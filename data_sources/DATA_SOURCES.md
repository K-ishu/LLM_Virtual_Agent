# Data Sources

This project uses public online sources, but stores them locally before runtime.
This design improves reproducibility and avoids unstable live-web behavior during testing and presentation.

## 1. PURE Requirements Dataset

- URL: https://zenodo.org/records/1414117
- Use: general requirements-engineering corpus for requirement review and test generation examples.
- Download method: Zenodo public API in `download_datasets.py`.

## 2. Requirements Data Sets: User Stories

- URL: https://zenodo.org/records/13880060
- Use: examples of user stories for requirements elicitation and ambiguity review.
- Download method: Zenodo public API in `download_datasets.py`.
- Note: the dataset page includes licensing cautions about upstream user-story sources. Use for academic experimentation with proper citation.

## 3. FR_NFR_dataset

- URL: https://data.mendeley.com/datasets/4ysx9fyzv4/1
- Use: examples for distinguishing functional and non-functional requirements.
- Download method: manual download, because the portal may not expose a stable direct file URL.
- Place files in: `data/raw/fr_nfr_dataset/`.

## 4. OWASP User Security Stories

- URL: https://github.com/OWASP/user-security-stories
- Use: security/privacy acceptance criteria and security requirement examples.
- Download method: raw Markdown download from GitHub in `download_datasets.py`.

## Runtime Policy

- The application does not crawl the web during normal use.
- The optional RAG context is retrieved from `data/processed/` only.
- The benchmark is generated by `prepare_benchmark.py` and saved as `data/processed/eval_set.json`.
